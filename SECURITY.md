# Безопасность

## Поддержка

Разработка ведётся для текущей prerelease версии 0.1.0a2. SLA и долгосрочная поддержка пока не объявлены. Старые prerelease не получают отдельную ветку исправлений.

## Сообщение об уязвимости

Проверьте вкладку Security репозитория: используйте private vulnerability reporting, только если эта функция действительно доступна. Отдельный приватный канал сейчас не подтверждён. Не публикуйте credentials, реальные события, exploit data или внутренние endpoints в issue. Для обычной ошибки создайте обезличенное воспроизведение с синтетическими входами.

## Безопасное использование

- Получайте код и release assets из ожидаемого owner/repository и проверяйте checksum.
- Держите входы, отчёты и реальные журналы вне checkout; output игнорируется Git, но это не защита от ручного добавления.
- Просматривайте внешний Sigma/Atomic YAML до использования. Safe parse не подтверждает безопасность команды.
- `--lab-ack` выводит команду как текст. ShowDetails/CheckPrereqs/Cleanup исполняются только вручную в проверенной лаборатории.
- SHA256 manifest не подписан и не защищает от согласованной подмены всего пакета.

Полный аудит зависимостей/CVE и независимый security assessment не выполнены. [Модель угроз](THREAT-MODEL.md) описывает ограничения реализации.
