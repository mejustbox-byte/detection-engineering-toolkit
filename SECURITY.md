# Безопасность

Инструмент локально генерирует артефакты и планы. Он не устанавливает Atomic Red Team и не выполняет тесты. `--lab-ack` лишь добавляет команду запуска в план; ответственность за разрешение и изоляцию остаётся у оператора.

Не применяйте эмуляцию к production. Используйте одноразовую Windows VM и заранее проверенные YAML/модуль, snapshot, согласованные действия и доступ к SIEM. Не включайте credentials в cases, имена каталогов и отчёты.

При обнаружении уязвимости сначала подготовьте минимальный синтетический reproducer без персональных данных. Частный канал disclosure пока не настроен; не помещайте чувствительные детали в публичный issue. Настройка GitHub private vulnerability reporting входит в подготовку удалённого репозитория.

Версия 0.1.0a1 — разработка. Реальные лабораторные проверки и аудит CVE зависимостей ещё не выполнены. Offline CI прошёл на Linux и Windows; результаты приведены в VERIFICATION.md. Версии обновляются через review, обновление lock и оба backend regression tests.
