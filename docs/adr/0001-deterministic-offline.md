# ADR 0001: Детерминированный offline CLI

Статус: принято. Дата: 2026-10-09.

## Контекст

Цепочка от ATT&CK к запросу и лабораторному тесту должна быть проверяемой без SIEM credentials и изменений хоста. Произвольная генерация правила по одному ID создаёт ложное представление о полном покрытии техники.

## Решение

Использовать четыре конкретных авторских сценария, стабильные UUID, pySigma backend/pipeline и отдельный ограниченный evaluator. Atomic тест выбирается из локального YAML по GUID; парсинг и SHA256 используют один snapshot. Внешний Sigma конвертируется отдельно. Bundles записываются в новый каталог и проверяются по manifest. Python CLI не содержит shell/network runner.

## Последствия

Входы и outputs легко ревьюить; runtime не требует сети и secrets. Каталог узкий, predicate не универсален, SIEM mapping зависит от среды. Целостность без подписи не подтверждает подлинность. Реальная доставка, match и cleanup требуют ручного стенда. Будущий runner/API требуют нового ADR и модели угроз.
