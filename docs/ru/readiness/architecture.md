# Архитектура и повторное использование

Строгая загрузка контракта отчётов питает точную модель readiness-1.0. Scenario_for, generate_rule, validate_cases и convert — существующие API toolkit. Генерация валидирует структуру Sigma через pySigma, конвертация использует прежние Splunk/Defender backends. Validate_cases проверяет предикат сценария, а не исполнение Sigma.

Обёртка содержит оценку opsec-1.0 и каталог цепочек: label риска, техника, хеш правила, результаты конвертации и явно неподтверждённый provenance. Сырые события и execution ID не копируются, но risk/scope/chain ID требуют проверки приватности. Контроли независимы: отказ источника не делает локальную генерацию недоступной, а pass локального теста не доказывает доставку.
