# Матрица проверок

| ID | Свидетельство pass | Fail | not_tested |
|---|---|---|---|
| DET-001 | Заявлен доступный process-creation источник | Available false | Источник/доступность неизвестны |
| DET-002 | Mapping и поля положительных событий | Нет mapped-поля или поля положительного события | Нет mapping/положительных случаев |
| DET-003 | Совпали положительные/отрицательные предикаты, обе конвертации получены | Несовпадение предиката/пустая конвертация | Нет класса случаев/самих случаев |
| DET-004 | Полное свежее заявление доставки с нужным хешем | Заявленный отказ, иной хеш или давность | Нет исполнения/полного свидетельства |

Fail DET-001–003 имеет high, DET-004 — critical. Нужны Image для whoami/hostname, Image и CommandLine для ipconfig. Отрицательные случаи без полей намеренно проверяют non-match и не описывают сломанное положительное событие. Pass ограничен утверждением и не означает полноту техники.
