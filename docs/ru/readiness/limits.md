# Модель угроз и ограничения

Строгий readiness JSON отвергает дубликаты ключей, не-JSON константы, лишние поля, неверные типы и другие цепочки. Лимиты загрузчика — 8 MiB и глубина 64. До 100 цепочек; --max-chains уменьшает лимит. В readiness нет исполняемой команды. Выход создаётся эксклюзивно, ошибки не повторяют исходные данные readiness.

Остаются ложные заявления telemetry/delivery, чувствительные risk labels, гонки файлов и ошибки зависимостей/runtime. Конвертация не доказывает поведение развёрнутого запроса. Расширение не предоставляет live Windows VM, SIEM или Atomic-исполнение. Прежние команды сохраняют прежние ограничения; строгий readiness-загрузчик не означает глобальное усиление парсеров.
