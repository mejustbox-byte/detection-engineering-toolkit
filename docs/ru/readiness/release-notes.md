# Readiness alpha 0.1.0a3

Добавлены detkit readiness, три цепочки риск/событие/правило/тест, четыре проверки согласованности, общий контракт отчёта и явный user_supplied_unverified provenance доставки. Прежние 31 тест сохранены; расширенный набор локально проходит 55 теста. Генерация и обе backend-конвертации переиспользуются.

Это alpha-расширение: нет движка исполнения Sigma, SIEM-подключения, эмуляции и независимого подтверждения доставки. Синтетический пример даёт неполное покрытие из-за delivery not_run. Hosted CI трёх ОС и установленный wheel фиксируются после выполнения.
