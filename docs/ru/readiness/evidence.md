# Свидетельства доставки и provenance

DET-004 оценивается независимо от успеха фикстур/конвертации. Verified требует непустых execution ID, времени и хеша сгенерированного YAML. Хеш совпадает с точными байтами правила. Предельный возраст по умолчанию 30 суток, настраивается 1–3650; граница проходит, превышение на секунду — fail. Будущие даты отвергают вход.

Toolkit не получает SIEM-журналы, не проверяет execution ID и не удостоверяет заявление. Каталог всегда помечает provenance user_supplied_unverified. Успех проверки согласованности verified-заявления не равен независимо подтверждённой доставке. Not_run/unknown и неполные verified остаются not_tested. Заявленный отказ остаётся fail даже без метаданных.
