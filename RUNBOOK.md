# Эксплуатация

## Рабочий цикл

1. Выберите сценарий из `detkit list`; проверьте телеметрию и ожидаемые false positives.
2. Создайте пакет в новом приватном каталоге, проверьте manifest SHA256.
3. Сверьте fields и таблицы SIEM. SPL не добавляет ваш индекс; используйте согласованный диапазон времени и index. KQL требует DeviceProcessEvents.
4. Для Atomic возьмите проверенный upstream checkout, выполните atomic-list, прочитайте исходную procedure, зависимости, input arguments и cleanup.
5. Зафиксируйте GUID и YAML SHA256. Сформируйте план с конкретным GUID; command execute выводите только для разрешённой лаборатории.
6. Выполните ручной протокол из [LOCAL-PC.md](LOCAL-PC.md), сохраните реальные результаты отдельно от синтетических fixtures.

## Ошибки

| Симптом | Действие |
|---|---|
| Неизвестная техника | Проверить список; добавить новый reviewed сценарий, не подменять ID |
| Каталог уже существует | Выбрать новый путь; инструмент не стирает старые данные |
| GUID отсутствует | Проверить нужный YAML/commit и atomic-list |
| Backend exception | Зафиксировать версии, minimal synthetic rule и stderr |
| Offline pass, SIEM пустой | Проверить время, ingestion, таблицу, mapping, index и raw event |
| Отсутствует CommandLine | Проверить конфигурацию сборщика; не считать это отсутствием поведения |
| Частичная запись пакета | Не использовать пакет до проверки manifest; создать новый каталог |

## Хранение и обновление

Output приватен по умолчанию и игнорируется git. Генерируемые отчёты не отправляются по сети. Данные cases могут быть пользовательскими — проверяйте их перед публикацией. Обновление выполняется из reviewed commit с новым lock; храните commit, версии и SHA256 вместе с протоколом. Манифест не заменяет подпись источника.
