# Модель угроз

## Активы

Локальные файлы, целостность правил/запросов, корректность свидетельств и состояние лабораторного стенда. Реальные идентификаторы и события относятся к оператору и не должны попадать в публичные артефакты.

| Угроза | Мера | Остаточный риск |
|---|---|---|
| Shell injection в ID/GUID | ID regex, UUID parse; отсутствует shell runner | Оператор может вручную запустить вредоносную Atomic command |
| Unsafe YAML objects | safe_load | Alias/структурный exhaustion полностью не устранён |
| Большой вход | Чтение максимум 8 MiB + 1 | Размер разобранной структуры может превышать размер файла |
| Подмена Atomic после parse | Parse и hash из одного snapshot | Source SHA пользователя не удостоверяет upstream |
| Traversal manifest | Точный allowlist файлов и SHA256 формат | Подпись отсутствует; локальная гонка не предотвращается |
| Подмена пакета | Проверка отсутствия/лишних файлов и hashes | Атакующий может изменить и manifest |
| Ложное detection coverage | Experimental/low, not_run поля, отдельные уровни validation | Неверный SIEM mapping или tuning остаётся задачей оператора |
| Supply chain | Закреплённые пакеты и regression CI | Полный vulnerability audit не выполнен |

## Эксплуатационные границы

Нельзя считать проверку manifest подтверждением подлинности или безопасности команды. Нельзя считать positive synthetic case доказательством real detection. Копирование реальных журналов в git и запуск Atomic на production не входят в штатный процесс.

Лаборатория изолируется отдельно. Протокол: [LOCAL-PC.md](LOCAL-PC.md), сообщение об уязвимости: [SECURITY.md](SECURITY.md).
